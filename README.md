# Lab01 — первый спринт, инфохимия

Анализ Wine Quality: спирт, плотность и остаточный сахар в красном вине.

## Файлы

- `Lab01_Sprint1_Wine_Quality.ipynb` — основной ноутбук с кодом, графиками и результатами.
- `Lab01_Sprint1_Wine_Quality.html` — версия для чтения в браузере, работает без интернета.
- `data/winequality-red.csv` — исходные красные вина из предоставленного архива, без изменений.
- `data/winequality.names` — описание авторов датасета.
- `results/` — полные таблицы метрик, частот и повторных отборов.
- `requirements.txt` — необходимые Python-пакеты.

## Запуск

1. Распаковать весь архив, сохранив папки.
2. Открыть `.ipynb` в Jupyter, VS Code с поддержкой ноутбуков или Google Colab.
3. Выполнить ячейки сверху вниз (Run All / «Выполнить все»).

Для локального окружения можно установить пакеты командой `pip install -r requirements.txt`.
Если открыть только ноутбук, он загрузит CSV с официального адреса UCI через интернет.
Для работы без интернета CSV должен оставаться в `data` рядом с ноутбуком.
Статические результаты сохранены; для их просмотра запуск не нужен.

## Проверка

Последовательно выполнены все 16 кодовых ячеек в свежей сессии IPython.
Сохранены 11 рисунков. Проверены суммы вероятностей, взвешенные ожидания,
нормализация, неповторяемость индексов при отборе без возвращения и точность полного охвата.
Использовано ровно три формальные гипотезы зависимости с поправкой Бонферрони.
Генератор случайных чисел как предмет второго спринта не реализован.
Случайный отбор в первом спринте выполняется стандартными средствами NumPy.

Окружение проверки: Python 3.12.14, NumPy 2.3.5, pandas 2.2.3,
SciPy 1.17.0, Matplotlib 3.10.8.

## Данные и источники

Cortez P., Cerdeira A., Almeida F., Matos T., Reis J. (2009).
Wine Quality. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T
Лицензия исходного датасета: CC BY 4.0.
В данном наборе используется `winequality-red.csv`: 1599 строк, 12 столбцов.
Белые вина из исходного архива не используются.

Полная литература и ограничения выводов указаны в конце ноутбука.
Официальные `cat_id` и `coeff` не выдуманы: в таблице стоят прочерки.
