# Lab01 — sprint 2

Генерация плотности красного вина на основе исправленного первого спринта.
В основе генератора — смесь двух нормальных распределений. Компоненту выбираем
по весам, затем генерируем её значение полярным методом. Для сравнения
оставлены одна нормальная модель и эмпирическая инверсия.

- **Lab01_Sprint2_Wine_Quality.ipynb** — расчёты, формулы и выводы с сохранёнными результатами.
- **Lab01_Sprint2_Wine_Quality.html** — версия для чтения без запуска кода и без сети.
- **data/** — красный набор из 1599 записей, без изменений.
- **lab01_tools/** — код подгонки и разбиения из первого спринта.
- **research/** — генераторы, проверка реализации, контроль по блокам и протокол.
- **results/** — таблицы метрик, проверок и пример генерации.

## Запуск

Распакуйте архив. В Jupyter откройте ноутбук в распакованной папке.
Установите зависимости командой:

    python -m pip install -r requirements.txt

Выполните ячейки сверху вниз. Чтобы пересчитать только проверки из терминала:

    python -m research.validate_models

В Colab можно открыть IPYNB и загрузить ZIP через боковую панель «Файлы».
В отдельной ячейке до запуска расчётов распакуйте архив:

    !unzip -q Lab01_Sprint2_Wine_Quality.zip

Если Colab сообщает об отсутствующих зависимостях, установите их:

    %pip install -r Lab01_Sprint2_Wine_Quality/requirements.txt

## Результат

Для 50 000 чисел смеси максимальный разрыв между CDF генерации и её законом
составил 0.00310 при границе 0.00872. На пяти контрольных блоках средний разрыв
между CDF генерации и записей — 0.0706 у смеси, 0.0829 у одной нормальной
и 0.0704 у эмпирической инверсии. У смеси 23 сравнения из 25 в допусках.
Два отклонения относятся к хвостовым квантилям на блоке 4 и вероятности
превышения 0.997 г/см³ на блоке 5. Это внутренняя проверка на исходном наборе.
