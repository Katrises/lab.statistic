# Протокол второго спринта

Используется красный CSV из исправленного первого спринта: 1599 строк.
Для плотности основной закон — смесь двух нормальных, выбранная в первом
спринте по CDF на пяти блоках. Параметры смеси оцениваются тем же кодом
из lab01_tools. Смесь моделируется методом композиции: выбор компоненты
по весам и полярная генерация внутри неё. Для сравнения оставлены
одна нормальная модель и эмпирическая инверсия.

На полном наборе сверяем генератор с заданным законом и сравниваем с исходной
таблицей. Это сравнение с данными подгонки. Для внутреннего контроля повторяем
те же пять групповых блоков: в каждом заново оцениваем параметры по четырём
блокам и сравниваем с оставшимся. Полные повторы не разделяются.
Выбор семейства уже сделан в первом спринте по этому набору, поэтому
блоки не заменяют независимую проверку на новых данных.

На метод и блок генерируем 50 000 значений. Seed полной генерации:
20261111, 20261112, 20261113 в порядке «смесь, нормальная, инверсия».
На блоке b (1–5): 20261111 + 10*b + j, j=0,1,2 в том же порядке.
Меряем различие CDF генераций и отдельно CDF теоретических моделей.

Сохраняются прежние учебные допуски: абсолютная ошибка среднего, делённая
на σ обучения, ≤0.15; относительная ошибка стандартного отклонения ≤0.10;
W₁ / σ обучения ≤0.15; максимальная ошибка Q05 и Q95 / σ обучения ≤0.35;
абсолютная ошибка вероятности D > 0.997 ≤0.05. Для проверки кода отдельно
используется граница Дворецкого — Кифера — Вольфовица при δ=0.001.
