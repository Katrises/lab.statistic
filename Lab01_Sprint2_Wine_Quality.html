random 01 — плотность красного вина

Description

Величина — плотность записи, выбранной из таблицы красного вина, в г/см³. В исходном файле 1599 строк. Сохраняем все записи и их кратности, как в первом спринте: крайние значения сами по себе не доказывают ошибку измерения. Отбор по оценке качества там отвечал на отдельный вопрос о составе групп. Здесь нужна модель для полного файла, поэтому по качеству записи не фильтруем.

Для плотности на пяти блоках среднее расхождение теоретической CDF с данными уменьшилось примерно с 0.0833 для одной нормальной до 0.0717 для смеси. Проверим, воспроизводит ли генератор эту модель и насколько сгенерированные плотности близки к данным. Смотрим также на хвостовые квантили и вероятность : близких средних для такой проверки мало. Значение 0.997 г/см³ взято как порог сравнения, а не как граница качества вина.

3. Контроль по пяти блокам первого спринта

Повторяем то же разбиение, при котором полностью совпадающие строки находятся в одном блоке. Каждый раз оцениваем параметры на четырёх блоках, генерируем 50 000 чисел и сравниваем с пятым блоком, который не участвовал в этой подгонке. Семейство смеси уже было выбрано по этому набору, поэтому результаты отражают внутреннюю проверку. Для независимой оценки нужны новые измерения.

Среднее, хвостовые квантили и расстояние Вассерштейна сравниваем на шкале стандартного отклонения обучающей части. — площадь между CDF, а из предыдущей проверки — наибольший вертикальный разрыв. Для стандартного отклонения берём относительную ошибку по контрольному блоку. Для события используем абсолютную разницу долей. Учебные допуски заданы в протоколе заранее; это критерии близости, а не пять статистических тестов.

resume

  1. Генератор воспроизводит заданную смесь. Автотесты пройдены. Расхождение между CDF генерации и формулой смеси — 0.00310 при границе 0.00872. Веса компонент в симуляции близки к оценённым весам.
  2. Смесь лучше одной нормальной по форме. На пяти контрольных блоках средний максимальный разрыв между CDF генерации и CDF наблюдений составил 0.0706 вместо 0.0829. Средняя ошибка тоже уменьшилась, с 0.1341 до 0.1275. Эмпирическая инверсия дала близкий разрыв 0.0704, а одна нормальная дала меньшую среднюю ошибку хвостовых квантилей. Поэтому преимущество смеси зависит от того, что сравниваем.
  3. Совпадение не полное. В допуске 23 из 25 сравнений. По среднему, стандартному отклонению и прошли все блоки. На блоке 4 ошибка достигла 0.357 стандартного отклонения обучения при допуске 0.35. На блоке 5 доля значений с равна 47.34% в контроле и 41.47% в генерации: разница 5.87 процентного пункта при допуске 5.

Смесь подходит как гладкое приближение для моделирования плотности из этого набора. Если нужна доля выше конкретного порога в самой таблице, её лучше посчитать по записям. При переносе на новые вина сначала стоит проверить модель на новых измерениях.
